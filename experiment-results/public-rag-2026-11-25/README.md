# 公开安全知识 RAG 实验结果

本目录归档截至 2026-11-25 的本地实验报告、配置、逐题排序及校验摘要。源码起点与运行时源码提交在 archive-manifest.json 中记录。本分支用于结果审阅，源码提交仍保存在本地开发分支。

## 已执行结果

- 公开语料初次入库为 5247 个片段和 25579 条显式关系。
- 初步质量审查、字符切块得到 5254 条候选片段，token 切块得到 5432 条。两次 token 构建的 SHA-256 一致，原文字符范围回查通过。
- 固定 BGE-M3 模型的 200 片段 CPU 性能探针已运行。512-token 探针截断 32 条，1024-token 先导实验实际输入最长 871 tokens，截断 0 条。
- 200 片段先导实验比较 BM25、BGE-M3 和 RRF，包含 55 个可回答开发问题。Recall@10 分别为 0.9545、0.9636、1.0000。MRR@10 分别为 0.8302、0.9051、0.8743。nDCG@10 分别为 0.8510、0.9101、0.8990。
- 先导实验验证向量文件独立进程重载、文件哈希、单位范数及一个来源过滤条件下三种检索模式的一致性。

## 指标适用范围

当前相关性标签由助手拟定。先导子集主动包含开发问题的相关证据，问题多由资料标题产生，拆分后的子片段继承父片段草稿标签。以上指标用于验证实验流程，全量检索性能和独立人工评测仍待执行。

旧 13 片段、12 查询结果位于 outputs/apt-rag，使用 TF-IDF 与 SVD 向量。新版先导实验使用本地预训练 BGE-M3，两个阶段的语料、标签及模型不同。

## 阅读顺序

1. reports/token600-pilot.md 记录最新实验的方法、限制和修正记录。
2. experiments/token600-pilot200/summary.json 保存指标和资源开销，per-question.json 保存逐题排名。
3. public-build 记录质量报告和快照哈希。evaluation/tasks-v2 保存开发题草稿及划分配置，测试题的内容哈希记录在 archive-manifest.json。
4. reports/investigation-round.md 说明任务查询接口、运行记录和切块对比的阶段状态。

archive-manifest.json 对归档数据文件逐项给出 SHA-256。这里的哈希提供完整性检查，来源语料、模型和索引的重建还依赖完整本地源码及固定下载快照。硬件测量采用 CPU，内存字段需区分采样峰值和结束时 RSS。

## 尚待完成

正式 corpus-v1 冻结仍需完成许可核验、重复审查及关系端点 T1579 的确认。两条超长 Sigma 规则约 26879 与 148740 tokens，需要单独设计检索表示与原文回查。全库中 114 个片段超过先导实验的 950-token 预筛预算。独立人工标签、全量向量索引、检索消融和 OTRF 公开事件联调也仍待完成。
